# MEDUZA SYSTEM — Core v0.1

Первый каркас системы управления автопарком.

## Стек
- Next.js + TypeScript
- Supabase PostgreSQL
- Supabase Auth
- Supabase Storage
- Tailwind CSS

## Что уже заложено
- пользователи и роли
- собственники
- автомобили
- история пробегов
- документы
- задачи
- уведомления
- audit log
- лента событий автомобиля

## Следующий этап
1. Создать проект Supabase.
2. Выполнить `supabase/schema.sql`.
3. Создать Next.js приложение.
4. Добавить переменные из `.env.example`.
5. Подключить реальные запросы к таблице `vehicles`.
6. Сделать авторизацию и права доступа.

## Основной принцип
Автомобиль имеет неизменяемый UUID и отдельный читаемый код вида `CAR-000001`.
Госномер, водитель, собственник и статус могут меняться без потери истории.
